# SONIC LEDGER — DOCUMENTACIÓN TÉCNICA
## CU09 (Playlists) & CU10 (Favoritos)

### 1. Resumen Ejecutivo
Se implementaron de forma unificada **CU09 — Crear y gestionar playlists** y **CU10 — Gestionar canciones favoritas** para toda la plataforma Sonic Ledger (Backend NestJS + TypeORM + PostgreSQL, Web React + TypeScript + Vite y Móvil Android React Native + Expo).

Ambos casos de uso comparten infraestructura de persistencia, DTOs, resolución polimórfica de pistas (`LOCAL` y `AUDIUS`) y modelos de API cliente, optimizando el consumo de recursos y manteniendo total compatibilidad con CU01–CU08 y CU06 sin modificar archivos de audio existentes ni almacenar archivos de proveedores externos.

---

### 2. Base de Datos y Persistencia

#### Migración incremental
- **Archivo:** `backend/src/migrations/1794488000000-PlaylistsYFavoritos.ts`
- **Tablas creadas:**
  1. `playlists`:
     - `id`: UUID (Primary Key).
     - `usuario_id`: UUID (Foreign Key a `usuarios(id)`, `ON DELETE CASCADE`).
     - `nombre`: varchar(100) NOT NULL.
     - `descripcion`: text NULL.
     - `created_at`: timestamptz.
     - `updated_at`: timestamptz.
     - Índices: `IDX_playlists_usuario_id`.
  2. `playlist_tracks`:
     - `id`: UUID (Primary Key).
     - `playlist_id`: UUID (Foreign Key a `playlists(id)`, `ON DELETE CASCADE`).
     - `track_id`: varchar(100) NOT NULL (identificador UUID de pista local o ID de Audius).
     - `source`: varchar(20) NOT NULL (`LOCAL` | `AUDIUS`).
     - `position`: integer NOT NULL.
     - `created_at`: timestamptz.
     - Restricción de unicidad: `UQ_playlist_track (playlist_id, track_id)`.
     - Índices: `IDX_playlist_tracks_playlist_id`.
  3. `favorite_tracks`:
     - `id`: UUID (Primary Key).
     - `usuario_id`: UUID (Foreign Key a `usuarios(id)`, `ON DELETE CASCADE`).
     - `track_id`: varchar(100) NOT NULL.
     - `source`: varchar(20) NOT NULL (`LOCAL` | `AUDIUS`).
     - `created_at`: timestamptz.
     - Restricción de unicidad: `UQ_usuario_favorite_track (usuario_id, track_id)`.
     - Índices: `IDX_favorite_tracks_usuario_id`.

### 3. Backend (NestJS + TypeORM)

#### Módulo y Entidades
- `backend/src/library/library.module.ts`: Registrado en `backend/src/app.module.ts` y `backend/src/data-source.ts`.
- `backend/src/library/playlist.entity.ts` (`Playlist`): Entidad TypeORM para playlists.
- `backend/src/library/playlist-track.entity.ts` (`PlaylistTrack`): Entidad TypeORM para pistas de playlist.
- `backend/src/library/favorite-track.entity.ts` (`FavoriteTrack`): Entidad TypeORM para pistas favoritas.

#### DTOs y Validación
- `backend/src/library/library.dto.ts`:
  - `CreatePlaylistDto`: `nombre` (1–100 carácteres), `descripcion` opcional (máx 500 carácteres).
  - `UpdatePlaylistDto`: `nombre` y `descripcion` opcionales.
  - `AddTrackDto`: `trackId`, `source` (`'LOCAL' | 'AUDIUS'`).
  - `ReorderTracksDto`: `trackIds` (array de string).
  - `FavoriteDto`: `trackId`, `source` (`'LOCAL' | 'AUDIUS'`).
  - `CheckFavoritesDto`: `trackIds` (array de string).

#### Servicio (`backend/src/library/library.service.ts`)
- **Resolución híbrida (`resolveTracks`):**
  - Para canciones `LOCAL`: Carga entidades `Cancion` publicadas con su relación `artista` y `genero`.
  - Para canciones `AUDIUS`: Resuelve los metadatos a través de `AudiusDiscoveryService` sin almacenar audio ni crear registros fantasma en la tabla de canciones propias.
  - Pistas no disponibles o eliminadas se marcan con `playable: false` sin romper la playlist.
- **CU09 Operaciones:** `listPlaylists`, `getPlaylistDetail`, `createPlaylist`, `updatePlaylist`, `deletePlaylist`, `addTrackToPlaylist`, `removeTrackFromPlaylist`, `reorderTracks`.
- **CU10 Operaciones:** `listFavorites`, `listFavoriteIds`, `checkFavorites`, `toggleFavorite`.

#### Controlador y Rutas (`backend/src/library/library.controller.ts`)
- Prefijo: `/api/auth/library` (con `JwtGuard` para todos los roles autenticados `CLIENTE`, `ARTISTA`, `ADMIN`):
  - `GET /api/auth/library/playlists`: Listar playlists del usuario.
  - `POST /api/auth/library/playlists`: Crear playlist.
  - `GET /api/auth/library/playlists/:id`: Detalle de playlist y canciones resueltas.
  - `PATCH /api/auth/library/playlists/:id`: Editar nombre y descripción.
  - `DELETE /api/auth/library/playlists/:id`: Eliminar playlist propia.
  - `POST /api/auth/library/playlists/:id/tracks`: Añadir canción (`LOCAL` o `AUDIUS`).
  - `DELETE /api/auth/library/playlists/:id/tracks/:trackId`: Quitar canción.
  - `PUT /api/auth/library/playlists/:id/tracks`: Reordenar canciones.
  - `GET /api/auth/library/favorites`: Listar canciones favoritas con metadatos.
  - `GET /api/auth/library/favorites/ids`: Listar IDs de favoritas del usuario.
  - `POST /api/auth/library/favorites/check`: Comprobar estado de favoritas por lote.
  - `POST /api/auth/library/favorites`: Marcar canción como favorita.
  - `DELETE /api/auth/library/favorites/:trackId`: Quitar de favoritas.

### 5. Frontend Web (React + Vite)
- **Componente Principal (`frontend/src/UserLibrary.tsx`):**
  - Pestañas dinámicas: "Mis Playlists" y "Mis Favoritas".
  - Grid de tarjetas de playlists con información de número de canciones.
  - Vista de detalle de playlist: Cabecera, botones de acción (Reproducir, Editar, Eliminar), y lista de canciones reordenables con botones Up/Down y Quitar.
  - Vista de favoritos: Listado de pistas con insignia SL/Audius, duración, botón de reproducción, quitar de favoritas y agregar a playlist.
  - Modal reusable `AddToPlaylistModal` para incorporar pistas a cualquier playlist del usuario.
- **Rutas (`frontend/src/App.tsx`):**
  - `/mi-musica` -> `<UserLibrary />`
  - `/playlists` -> `<UserLibrary />`
  - `/favoritos` -> `<UserLibrary />`
- **Integración con Navegación y Reproductor:**
  - `Catalog.tsx`: Enlaces activos a Playlists y Favoritos en sidebar y barra inferior móvil. Botones de corazón y `+ Playlist` integrados en cada canción y en el detalle.
  - `Playback.tsx`: Los botones de corazón en `MiniPlayerWeb` y `FullPlayerWeb` ahora alternan el estado favorito de la canción en reproducción en tiempo real.
  - `ArtistReleases.tsx`: Sidebar actualizado para enlazar directamente a `/playlists` y `/favoritos`.
