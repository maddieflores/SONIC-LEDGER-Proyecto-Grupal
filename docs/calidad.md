# Evidencias previstas de calidad

| Factor | Evidencia pendiente durante implementacion |
| --- | --- |
| Correcto | Requisito -> criterio de aceptacion -> prueba -> evidencia |
| Fiable | Compra concurrente sin sobreventa, pagos idempotentes, QR de un uso |
| Portable | Instalacion reproducible, navegadores objetivo, APK en Android real |
| Mantenible | Modulos por dominio, migraciones, tipado y API documentada |
| Usable | Flujos completos, accesibilidad, mensajes y recuperacion de errores |
| Seguro | Hash de claves, autenticacion, autorizacion por rol/propiedad y validacion |
| Eficiente | Medicion de latencias y carga declarada, indices y paginacion |

No usar esta tabla como prueba de cumplimiento. Completar con resultados reales durante el desarrollo.
